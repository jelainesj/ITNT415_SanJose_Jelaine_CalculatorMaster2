Project Description
Calculator Master is a menu-driven Python calculator developed using Git and GitHub branching. The final version integrates all required arithmetic operations into a single application.

Branch Structure
The project was developed using the following feature branches:

addition_SanJose – Addition

subtraction_SanJose – Subtraction

multiplication_SanJose – Multiplication

division_SanJose – Division

Each feature branch was developed separately and merged into the main branch through the GitHub Pull Request workflow.

Program Features

The calculator includes the following features:

Addition

Subtraction

Multiplication

Division

Numeric input validation

Invalid menu option handling

Division-by-zero handling

Continuous menu execution until the user selects Exit
